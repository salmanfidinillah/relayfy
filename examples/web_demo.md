Daftarkan akun pemberi dan penerima milik penguji. Tidak ada akun/password bawaan.

## Sumber 1 — Catatan proyek (bagikan ke pemberi dan penerima)

```text
Tujuan: Membangun website toko.
Peluncuran: 6 November 2026
Kontak: Andi, pemilik proyek.
```

## Sumber 2 — Ekspor chat (bagikan ke pemberi dan penerima)

```text
Peluncuran: 8 November 2026
Hambatan: Peluncuran tertunda karena foto produk belum dikirim klien.
Keputusan: Gunakan katalog statis untuk demo.
```

```text
TASK|Landing page|done|Andi|2026-11-02||
```

## Sumber privat — Hanya pemberi

```text
Anggaran Kenari: Rp50.000.000
```

## Pertanyaan

- Mengapa peluncuran tertunda? → sumber chat, tanpa mengarang.
- Kapan peluncuran? → kedua tanggal dan klarifikasi otoritas.
- Siapa PIC pembayaran? → belum tercatat; kutipan task.
- Anggaran Kenari? (akun penerima) → respons tidak diketahui yang sama seperti sumber tidak ada; tanpa menyebut ada dokumen privat.

Tanpa API key: coba Ask/brief AI untuk melihat error konfigurasi. Gunakan tombol “Susun ringkasan bukti” untuk menguji review/accept tanpa mengklaim AI sudah berjalan.

Review: pemberi menyusun draf untuk penerima → tinjau & bagikan → preview → konfirmasi. Penerima baru dapat melihat versi sesudah dibagikan. Penerima dapat meminta klarifikasi atau menerima setelah meninjau.

Revokasi: pemberi membuka tab Sumber → Akses → cabut penerima dari chat → preview → konfirmasi. Pada permintaan penerima berikutnya kutipan chat, brief lama, dan riwayat revisi lama tidak tampil dan tidak diteruskan ke model. Materi yang sudah terlihat tidak dapat ditarik kembali.
